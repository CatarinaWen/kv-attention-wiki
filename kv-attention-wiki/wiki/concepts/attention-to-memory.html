注意力到記憶 Attention → Brand Memory

一句話：廣告被看到只是第一步，品牌被看到、被記住才算有效。

重點

  • 廣告太多（clutter）的環境裡，抓住並留住注意力越來越難S04
  • 沒有注意力就不可能有效，但注意力本身不夠，要在記憶裡留下品牌S04
  • 注視在品牌上（其次是圖像）累積的資訊，讓品牌辨認更準、更快S04
  • 模型假設影響記憶的是注視的次數，而不是每次看多久S04
  • 品牌元素也最會把視線轉送到廣告的其他部分S05

對 KV 的意思

  • 熱圖上「最亮的地方」如果不是品牌，KV 可能被看了卻沒被記住S04S05
